# Aura Brew - Enterprise Coffee Shop CMS

Production-ready, white-label coffee shop platform.

## Quick Start

1. Clone: `git clone https://github.com/jakeharvey162-source/Aura-brew-.git`
2. Install: `npm install`
3. Setup: Copy `.env.example` to `.env.local`
4. Dev: `npm run dev`
5. Admin: Visit `/admin/register` to create Super Admin

## Access Admin

- Register: `/admin/register`
- Login: `/admin/login`
- Dashboard: `/admin/dashboard`

## Environment Variables

See `.env.example` for all required variables.

## Deploy to Vercel

1. Push to GitHub
2. Import to Vercel
3. Add environment variables
4. Deploy
